# 📘 SemPilot

**Academic Damage Report Engine™**

SemPilot is a CGPA intelligence system that helps students understand their academic trajectory, predict required performance, and plan recovery strategies.

It goes beyond a simple CGPA calculator — it simulates what you need to score next and evaluates how realistic your academic goals are.

---

## 🚀 Features

- 📊 Live CGPA calculator
- 🎯 Target CGPA prediction
- 📈 Required SGPA estimator
- ⚠️ Feasibility analysis (Achievable / Moderate / Hard / Impossible)
- 🧠 Academic risk & “damage” assessment logic
- 📉 Modular backend CGPA engine with test coverage
- ⚡ Real-time interactive React UI

---

## 🧠 Core Engine

SemPilot is powered by a modular academic intelligence engine:

- `calculateCGPA()` → computes weighted CGPA
- `predictRequiredSGPA()` → calculates required performance per semester
- `computeFeasibility()` → evaluates difficulty level of target
- `analyzeBacklogs()` → assesses academic risk from failed subjects
- `projectCGPATrend()` → forecasts future CGPA progression

# SemPilot

SemPilot is a React-based academic analytics engine.

Core features:

- Required SGPA prediction
- CGPA recovery modeling
- Backlog impact analysis
- Credit-weighted recovery roadmap

Core assumption:
Backlog subjects currently contribute 0 grade points.
After reattempt, the engine assumes recovery to ~6 grade points baseline.

Goal:
Transform raw SGPA calculations into actionable student-readable recovery planning.
